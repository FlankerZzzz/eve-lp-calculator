# 旗舰跳跃业务逻辑与随机测试报告

日期：2026-10-19。范围：当前工作区与已运行服务中的旗舰自动规划、手动规划及不可达接续；按用户最后确认的规则验收。

## 结论

本轮所测范围内，未发现业务规则与代码执行不一致、非法跳跃／过门、错误完成或错误复制问题。随机真实星图结果与独立寻路对照一致。

本轮只增加本地测试证据及本报告；未修改业务实现、未部署、未触发同步／重算或写入业务数据库。测试使用只读接口、只计算的规划 POST、独立浏览器会话与内存故障注入。后台自然运行的定时同步不属于本轮测试操作。

## 业务规则与实现核对

| 最终业务规则 | 核对点与结果 |
| --- | --- |
| 非高安目的地全程旗舰跳，禁止过门中转 | 自动搜索不扩展此类星门边；逐段验证与页面返回校验均通过 |
| 高安目的地仅允许末段过门 | 搜索区分跳跃阶段／高安收尾阶段，每道星门落点必须高安；过门后不允许再跳跃。服务端与页面校验一致 |
| 舰船高安准入始终有效 | 沿用已确认的黑隐、战略货舰、巨像与山岳允许范围；其余舰船的高安端点及中间节点被拦截 |
| NPC 站开关只限制自动旗舰跳落点 | 开关开／关均测试；不要求起点、星门收尾落点有站；手动及接续允许用户选择无站合法落点 |
| 入侵规避开启后排除所有安等、所有途经节点 | 包含起终点、途经点、跳跃起落点与星门中间点；关闭不按入侵筛选 |
| 入侵数据失效不能当作安全 | 自动读取、失败重试、自然过期、后台更新覆盖与恢复均测试；开启规避时暂停规划并隐藏失效完成／复制 |
| 波赫文不能作为普通旗舰跳起落点 | 自动候选排除，手动追加拦截；包含随机波赫文端点及页面操作测试 |
| 按顺序经过途经点，重复点需要真实再次访问 | 独立状态搜索及页面进度对照；撤销、变更草稿和重复起点均覆盖 |
| 不可达保留合法前缀，在中断点转手动 | 独立检查前缀达到的最大途经进度、到下个目标的距离及同分成本；原起终点／途经点保留，空前缀从 A 接手 |
| 未完整到达不显示完成和完整复制 | 覆盖非空／空前缀、手动接续、技能失效、入侵更新及异常服务端路线 |
| 自动与自动转手动接续不限制为 30 段 | 本轮真实随机样本有 44／40／34 跳完整路线；44 跳另在真实桌面页面验证；全新手动 Demo 的限制保持独立 |
| 合法完整路线按门数、旗舰跳次数、燃料依次择优 | 不复用自动引擎的独立最小成本搜索对照通过；手动星门按最短实际门数单独验证 |
| 航程和燃料按舰船、技能与三维坐标计算 | 核对基础航程乘校对加成、两个燃料修正独立乘算、每段燃料向上取整，全部舰船技能组合通过 |

主要实现核对：[自动引擎](../lib/jump-auto-planner.mjs)、[手动与合法性校验](../lib/jump-planner.mjs)、[自动接口](../app/api/navigation/jump/auto/route.ts)、[页面状态与接续](../app/navigation/jump/page.tsx)、[入侵策略](../lib/navigation-avoid.mjs)。

## 真实星图随机测试

随机种子：`2026101951`。使用实际公开目录中的 63 艘舰船、5,485 个星系和 6,989 条星门连接。

- 每艘舰船随机两组，共 126 组；另加此前用户线路等 16 组命名回归，总计 142 组实际 API 请求。
- 三种技能均覆盖 0～5 级；混合长／短距离、高／低安／零零目的地、波赫文端点、重复途经点及屏蔽开关。包含 20 组带途经点的请求。
- NPC 站开／关各 71 组，入侵规避开／关各 71 组；不以“全部关闭限制”的单一配置代替随机测试。
- 独立参考搜索自行构造星门邻接、三维范围候选、舰船准入及阶段状态，不调用自动引擎、`inspectLeg` 或其启发式／前缀选择实现。
- 对完整路线比较实际门数、跳跃数和逐段取整总燃料；对不可达结果比较完整路线确实无解、前缀合法性及中断点选择；应拦截端点单独验证错误响应。

| 结果 | 数量 |

| 不可达，合法前缀及中断选择一致 | 56 |
| 应拦截的高安准入／规避端点 | 8 |
| 计算预算保护触发 | 0 |

## 边界与证据

- 本轮证明的是给定资料和约束下的选路与交互，不验证游戏内玩家建筑、诱导角色、权限、舰船实际停靠条件或实时敌情。
- 坐标、站点和舰船来自现有快照；入侵使用每次真实请求返回的缓存快照。最优成本以项目当前光年换算及取整口径对照。
- 随机抽样及界面模拟不等于穷尽全部星系组合或代码覆盖率 100%；计算时间／工作量保护仍然存在。
- 新增本地证据脚本位于被忽略的运行目录：`jump-random-business-audit-20261019.mjs`、`jump-current-manual-browser-audit-20261019.mjs`、`jump-current-lifecycle-browser-audit-20261019.mjs`、`jump-live-random-browser-audit-20261019.mjs`。标准 `checks` 仍可直接重跑。
