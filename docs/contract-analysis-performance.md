# 合同分析性能优化

保持原有名称归一化、同名歧义保护、物品 ID 查询、未匹配展示与价格计算规则。

- 名称匹配：请求内建立中文名、英文名和 ID 对照，外部查询补齐后重新建立一次，避免四轮全列表扫描。
- 外部名称查询：优先本地目录，仅对缺失名称查询 ESI。相同名称集合共享请求；成功返回的数据（包括查无结果）缓存十分钟。网络错误和格式错误不缓存。缓存最多 128 组，过期或容量超限时清理；进程重启后清空。不新增数据库表，不缓存市场价格。
- 前端：复用 ISK、数量格式化器及名称排序器，避免大量行各自创建格式化工具。

测试覆盖名称引号、空格、大小写、同名歧义、数字 ID、重复记录、缓存过期、并发合并、失败不缓存和容量限制。价格、历史、体积仍从原有本地数据查询，未匹配物品不计入合计。
