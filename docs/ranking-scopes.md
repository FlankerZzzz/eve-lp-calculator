# 独立榜单状态

热销榜（30 日日均交易量）和价值榜（税后单位 LP 利润）各自保存两种状态：

| API exclude | 候选范围 | ranking_cache.list_kind |
| --- | --- | --- |
| 0 / 未传 | 所有未屏蔽的有效方案 | popular / highRatio |
| 1 | 上述方案中 is_high_sec=Y 的方案 | popular_exclude / highRatio_exclude |

每个范围先筛选候选，再按兑换签名去重、排序、截取 Top 100。四份快照在同一事务发布，保留各自排名、快照日期和计算时间。候选不足 100 时如实返回，不使用另一状态补齐。

返回包含 exclude 和 rankingScope（all / highSec）。读取时仍按当前维护标记检查屏蔽状态；exclude=1 同时检查高安标记。缺少对应快照时返回空榜，不退回全局榜。首次上线需重算排行榜。

首页“仅展示高安势力”切换请求 exclude=1/0，并重置两榜分页。该开关不改变全局屏蔽规则、不修改目录或企业详情；增效剂蓝图显示开关仍为独立展示过滤。
