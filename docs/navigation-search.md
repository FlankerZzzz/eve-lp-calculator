# 导航星系搜索

常规导航与旗舰跳跃页在星图右侧新增独立“星系定位”。输入后点击候选或回车，平滑居中到星系及其星座范围；不更改起点、终点、途经点，不触发路线重算。普通导航聚焦模式下，定位会先退出路线聚焦，以便显示路线之外的目标。手机端不新增星图和定位浮层，继续使用功能输入框。

全部星系输入框共用 `SystemPicker` 和搜索索引：中文、英文、拼音全拼、拼音首字母、星系 ID。忽略大小写、空格、连字符和拼音声调。示例：吉他 / Jita / jita / ji ta / jt；安帕纳克 / anpanake / apnk。重名时保留候选，不以歧义拼音静默确定路线点；完整中文/英文/ID 精确匹配优先。

星系名称仍读取数据库导航目录；不修改物品或 LP 搜索。服务端用固定版本 pinyin-pro 生成衍生字段 `searchPinyin`、`searchInitials`，不新增数据库表，不将拼音字典打入浏览器。服务端按星图对象缓存，前端按目录数组共享索引，输入不发起接口请求。读音采用库的默认词语读音，特殊地名的多音别名若有需要可后续维护。

支持方向键、回车、Escape，中文输入法组合期间的回车不会误选候选。实现测试：`checks/system-search.check.mjs`；桌面与手机检查覆盖两种导航页面。

依赖用法依据：[pinyin-pro 官方说明](https://pinyin-pro.cn/use/pinyin.html)。
