# 星系地理缓存

## 来源与维护

SYNC 新增 `geography`（星系地理缓存）模块，默认开启自动同步，Cron 为 `0 * * * *`，时区沿用 Asia/Shanghai。支持现有可视化/Cron 计划编辑、自动开关、手动运行/恢复、暂停、重新同步以及 DEBUG 日志。首次上线单独触发一次。其他任务与既有计划不变。

| 缓存种类 | 数据来源 | 保存范围 |
| --- | --- | --- |
| system_jumps | 晨曦 ESI `/universe/system_jumps/` | 原始一小时批次，滚动 72 小时 |
| system_kills | 晨曦 ESI `/universe/system_kills/` | 原始一小时批次，滚动 72 小时 |
| incursions | 晨曦 ESI `/incursions/` | 最新成功快照，保留全部原始字段 |
| sovereignty | 晨曦 ESI `/sovereignty/map/` | 最新成功快照，保留全部原始字段 |
| industry | 晨曦 ESI `/industry/systems/` | 最新成功快照，保留全部活动系数 |
| map | 已导出的标准 SDE 星图文件 | 验证后发布到数据库，包含坐标、安等、星域/星座、星门、NPC 站点数量 |
| jump | 已导出的跳跃基础资料文件 | 验证后发布到数据库，包含舰船与 NPC 站点清单 |

每次动态同步获取五个全量数据源，不逐个请求星系。主权归属名称通过额外的去重 ID 批量请求补齐（目前一次批量请求），存入同一缓存表的 `sovereignty_names`，并随每小时同步更新；网页不现场查询名称。复用 V2 RequestPool 的并发、节流、重试、超时、错误预算、退避和取消逻辑。地理缓存优先级与排行榜相同，在长历史任务之前执行；沿用单 worker 租约，避免多写入器。

## 两张物理表

`navigation_cache`：主键 `kind`，字段 `payload`（完整 JSON）、`modified`（官方 Last-Modified）、`fetched`（成功入库时间）、`attempted`（最近尝试时间）、`error`、`version`（内容 SHA-256）。它同时保存静态与动态的最新成功快照，不为每个数据源另建表。

`navigation_samples`：主键 `(kind, window_end)`，字段 `fetched`、`payload`。只记录过门/击毁批次；`window_end` 为官方 Last-Modified 的 UTC ISO 时间，有时间索引。每次同步删除超过 72 小时的批次。最新缓存过期后仍可供展示参考，但会标记过期，不会冒充新数据。任务关闭时不会有清理进程运行；下次同步会补做清理。

同一个官方时间窗口重取不会增加记录；上游修订同窗口时替换该批次。不同接口分别记录时间，不能拼成一个虚假的共同窗口，也不能将滑动/重叠的一小时窗口直接相加为 24 小时值。停机造成的缺口不补零、不插值。当前未提供 24 小时汇总业务。

## 发布与错误

逐个验证完整数组及关键字段后，以事务发布该数据源的完整 JSON。非法响应、缺少统计 Last-Modified、未来时间或时间倒退均不覆盖旧快照；写入错误状态并让整个任务显示失败，其余有效数据源仍可独立更新。空入侵/活动列表是合法结果；空的主权/工业全量目录视为异常。请求失败不等同于“零活动”或“无入侵”。暂停/进程退出通过共享 AbortSignal 终止，已提交的快照持久化，恢复时安全重取且去重。

INFO/DEBUG 使用既有 `logs/geography` 模块日志，保留七天。DEBUG 可记录原始响应。SYNC 的缓存明细展示每个动态数据源条数、入库时间、官方时间与错误。

## 业务读取

网页通过只读 SQLite 连接读取 `navigation_cache`，不创建表、不访问上游，也不回退读取 JSON 文件。普通导航、路线规避入侵、地图悬停、选中卡片、旗舰跳入侵与站点入口均使用数据库。星图派生图结构可以按数据库内容版本在进程内缓存，数据库仍是数据源。

地图环境接口返回原有活动字段，以及 `sovereignty.rows` / `industry.rows` 的完整原始数组，均附带独立元数据。当前未新增主权/工业着色或计算公式，避免提前决定业务口径。

入侵等当前状态以最近成功同步后 75 分钟为新鲜度宽限；统计另检查官方窗口不得超过 125 分钟（按小时抓取可能拿到上一份官方批次），窗口始终原样展示，非实时。失败立即标记旧数据。前端每五分钟刷新的是本地数据库，不是每五分钟请求 ESI。

NPC 站点接口现在返回入库 SDE 清单，并明确标注 SDE，不再点选时请求 ESI 核实站名；SDE 清单没有站名时显示站点编号。玩家建筑发现和停靠权限仍待后续角色授权实现，不把 NPC 站点数量当成实际可停靠保证。

## 验证

`checks/geography-cache.check.mjs` 覆盖整批校验、跨连接持久化、错误保留旧值、合法空列表、窗口去重/修订、72 小时清理、时间异常、小时计划、任务优先级、单源失败隔离，以及生产只读入口无网络/文件回退。
