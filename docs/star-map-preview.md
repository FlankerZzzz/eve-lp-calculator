# 星际导航 · 常规星门导航

入口 `/navigation`，侧边栏“星际导航”。提供常规星门路线规划、途经点、三种路线偏好、路线自动缩放和星系活动分析；常规路线不混入旗舰跳跃边。

## 数据与隔离

- 从完整标准 SDE 的 `mapSolarSystems.jsonl`、`mapRegions.jsonl`、`mapConstellations.jsonl`、`mapStargates.jsonl` 生成快照，保留原始米制三维 `position`。星系附带实际星座 ID 和中 / 英文回落名称，校验星座所属星域一致；不使用二维示意位置。
- 仅包含新伊甸 ID 30000000–30999999；虫洞和深渊不混入地图。包含的特殊星系仍不代表可供旗舰跳跃。
- 中文和英文名来自 SDE；明确标示尚未与晨曦地图全量比对，不宣称国服完全一致。
- 不创建数据库表，不改现有 SDE 导入、同步计划、订单/合同/LP 计算规则。
- 快照位于 V2 数据目录下 `star-map.json`，沿用现有数据卷。只读 API `/api/data/star-map` 读取快照并缓存。桌面挂载地图时另批量读取一次环境资料（过门、击毁、萨沙名单），每 5 分钟及页面重新可见时复查，使用与路线分析相同的后端共享缓存。不是每次悬停请求上游。手机不挂载地图，也不加载这份全图环境资料。
- 快照缺失或损坏时返回 503，并显示错误，不生成虚假数据。不自动修改、下载或同步数据。

## 手动生成 / 更新

```bash
node scripts/v2/export-star-map.mjs docker-data/v2/sde.zip docker-data/v2/star-map.json
```

脚本全部解析和校验成功后，先写临时文件再原子替换快照。当前程序没有在 Sync 页新增任务，SDE 更新后需手动再次运行。快照不入 Git、不打进镜像。

## 渲染

使用 Three.js 批量星点与去重星门线；渲染坐标由米除以 9.46e15 转成光年，反转 Z 以转换坐标手性，距离计算始终基于原始三维坐标。像素密度最多 2，镜头未变化时不重复绘制，隐藏标签页停止绘制；退出页面释放 GPU 资源及事件监听。

星图改为深色底的小方点网络：普通星系约 3.5–4 像素，选中点和规划点约 6–8 像素。基础点、选中点、经停点及范围候选均不用径向纹理和加法发光。背景星门为一像素低亮度细线，在线段两端按对应星系安等颜色渐变，随同一配色配置更新。实际路线仍保留独立高亮；跳跃航程圈及繁忙统计提示属于功能覆盖层，不因去除星点光晕而删除。

PC：默认俯视、正北朝上；左键拖动平移，Shift＋左键或中键旋转，滚轮缩放。方向标只提供一个“回正”按钮，同时恢复俯视、正北朝上及默认全图观察中心和缩放；聚焦分析时适配完整选中路线。二维和三维行为一致。宽度 700px 及以下移动端只请求精简星系目录，不请求三维快照，不下载 Three.js 地图组件、不创建 WebGL；支持相同导航操作和分析列表。浏览器无法提供 WebGL 或上下文中断时显示明确错误，列表导航仍可使用。

## 常规导航操作

- 点击星系（或路线列表定位）时，镜头约 1.1 秒平滑移向该星系，并按所属星座的实际范围适配缩放，不再瞬间跳到固定倍率。目标星系居中，保留当前朝向；缩放采用对数插值与缓入缓出。拖动、滚轮、再次点选、回正或切换地图模式可打断 / 替换当前动画。系统“减少动态效果”启用时直接定位，避免强制动画。旧快照缺少星座时降级为局部定位，不猜测星座；需重新导出地图才能获得完整星座层。
- 地名按观察尺度逐层渐显：远景显示星域名，中景星座名，近景星系名；相邻层交叠渐变，选中星系名优先保留。每帧仅在镜头 / 内容变化时投影和屏幕避让，最多 72 个目标标签，约 220ms 淡入淡出；文字避开地图边缘、方向面板和信息卡，不拦截鼠标或触发请求。使用一个只读 HTML 覆盖层，不为几千个星系创建独立常驻 DOM 节点。二维与三维共用，聚焦分析保留既有路线标签而不叠加背景地名，旗舰规划标签优先、不重复显示同一规划星系名。
- 地图快照从 `npcStations.jsonl` 增补每个星系的 `npcStationCount`，只统计 NPC 空间站，不含玩家建筑。缺少该字段的旧快照显示“未核实”，只有完整读取站点表才能显示已知 0。两种卡片均标注 SDE 基线；该数字不是一小时统计，也不保证与晨曦当前站点全量一致。原始坐标、星门及业务数据库不变。

- 桌面星图无需点击即可悬停预览星系：鼠标停留约 100ms 后出现随鼠标定位的紧凑卡片。只展示名称、逐级安等色、星域 / 星座、NPC空间站数、萨沙状态，以及“过门次数 / 舰船击毁数 / 太空舱击毁数 / NPC击毁数量”四列统计，不再单列英文和 ID。活动区统一称“最近一小时的地理数据”，仍分别显示各自官方一小时窗口（北京时间），并不冒充严格以当前时刻截止的最近 60 分钟。经当前名单确认入侵时，名称左侧显示红字“警告：入侵星系”；名单失败 / 过旧显示待核实，不误报未入侵。真实 0 与未知 — 区分，旧数值带 * 提醒。无 24 小时参数，也没有新增采集历史或汇总表。
- 常规导航右侧选中卡与悬停共用同一份环境资料、格式化逻辑和完整指标名称；不再使用只有已计算路线才有值的旧活动对象，因此未计算路线也能看到活动数据。去掉额外英文 / ID 行，保留设置起点、终点、途经点和屏蔽操作；窄屏卡片可滚动，避免挡住方向面板。父页面仅在桌面开启一次环境读取并传给星图，不为两种卡片重复请求。
- 卡片自动避让地图及视口边缘、不拦截鼠标；移到空白、拖动/缩放、滚动、失焦或 Escape 即隐藏。二维/三维及聚焦视图一致；悬停只读已加载资料，不选点、不移动镜头、不触发接口，也不改规划；批量环境资料到达时可直接更新当前卡片，无需再次移动鼠标。点击仍用于固定选择和后续操作，手机沿用搜索/点选列表。

- 星图下方统一配色栏，默认并且当前只开放“安全等级”。按显示安等逐 0.1 分为 11 档：1.0 蓝、0.9 青蓝、0.8 青绿、0.7 绿、0.6 黄绿、0.5 黄、0.4 橙、0.3–0.1 逐渐橙红，0.0 及所有负安红。星点、安等文字及完整色阶图例共用同一份配色；不再按高/低/零安三档粗略着色。正安等最低显示 0.1，负安统一红色；这只影响显示，不改变安等判定、路线或距离。蓝端按用户要求加强辨识度，不宣称所有客户端主题的 RGB 完全一致。其他着色方法待确认后扩展；不存数据库、不触发查询，手机无星图也不展示配色栏。

- 方向面板提供“三维 / 纯二维”显示切换。二维使用正交投影，星点、星门、路线与标签统一压平到 XZ 平面；只允许平移和缩放、固定正北朝上，不修改原始地图数据或寻路规则。切换不丢失已计算路线与聚焦状态，手机不加载这两种星图。

- 中 / 英文名称及 ID 搜索选择起点、终点和途经点，最多 12 个点位。A/B/C 等按实际顺序标示。把手支持鼠标 / 触屏指针拖动，上下按钮支持键盘和触屏替代；可删除途经点或反转整个点位序列。
- 桌面可右键星系直接“设为起点 / 设为终点 / 添加途经点”；点击固定详情卡同样提供三种点位操作及屏蔽。追加途经点放在现有终点之前，按点击顺序保留，可重复选择同一星系，最多 10 个途经点；达到上限后禁用添加，起终点仍可修改。设置不移动镜头、不发起路线计算，已有结果标为待重算。右键操作窗支持 Escape、点击外部、滚动、窗口缩放和失焦关闭。
- 拖动把手时出现跟随指针的浮层卡片、虚线落位槽和邻近点位平滑让位。松手后约 170ms 落位动画结束才提交新顺序；拖动中不修改导航点位、不请求新路线。支持接近视口边缘自动滚动、Escape / 指针取消 / 窗口失焦取消，以及系统减少动态效果设置。手工上下移位同样有让位动画；不是自动路径优化。
- 必须点击“计算 / 重算”才计算新的路线。点位和规避修改后显示“仍展示上次路线”，不把旧结果冒充新结果。
- 每次明确计算得到全部三种路线；复选框只切换其显示，无须因勾选重复搜索。地图同时显示所有已勾选路线，重叠边采用不同线宽保留颜色。
- 高安优先：先最小化经过非高安星系的次数，再最小化星门跳数。最近优先：只最小化星门跳数。低安优先：先最小化高安星系次数，再最小化星门跳数；低安和 00 均为非高安。三种模式都不是硬性安等限制。
- 本地算法采用 Dijkstra；偏好代价为每次不偏好的安等进入附加 `星系数 + 1`，保证“安等优先、跳数其次”。每个有序途经点之间独立搜索并拼接，保留合法重复经过的星系。确定性邻接顺序确保同代价结果稳定。它不是对 ESI `secure/insecure` 隐含权重的复刻。
- 全部屏蔽规则是硬约束，起点 / 终点 / 途经点不例外；冲突报错，不自动绕过用户设置。无法连通的路线单独提示，不伪造直线导航。
- 桌面不再提供“聚焦分析”开关。每次成功计算／重算后自动缩放到当前勾选的全部有效路线：一条适配单线，两条或三条取所有途经点的联合包围范围。重复计算相同点位和路线也会重新定位；失败或旧请求不触发新的缩放。路线表格标签只切换分析对象，不改变多条线共同显示的范围。
- 高亮路线时保留全部背景星点，透明度降为 0.12，背景星门线降为 0.06（仍受显示连接开关控制）；路线和白色小方点保持醒目。不再切换纯黑隔离背景，也不收窄地图给旧聚焦统计浮层。非路线星系仍可点选定位，点选不清除路线。
- 已移除根据繁忙程度绘制的红色活动圈，不再使用星门活动量创建额外圈状几何。星系活动数据仍用于正常悬停、选中详情和手机表格，不等于删除活动资料。旧聚焦统计浮层和开启聚焦提示一并移除。
- 统计和环境资料更新不重新适配镜头。二维／三维切换保留观察位置和路线；再次重算时按当前投影适配全部路线。手机不加载星图，保留路线和活动列表。

## 规避数据与覆盖边界

- 本地保存键 `eve-navigation-avoid-v1`。包含始终屏蔽星系、三神裔手工标记、联合阵线手工标记以及三个规避开关；每份名单最多 500 个。仅当前浏览器保存，不增加表、不写服务器数据库、不同浏览器不共享。禁用本地存储或损坏配置会明确提示。
- 三神裔：SDE 波赫文星域 `10000070` 加手工名单。仅这一覆盖范围，没有假定低安或某个势力领地就是所有三神裔危险星系。
- 联合阵线（EDENCOM）：仅手工维护。本阶段没有经确认的晨曦完整公开 API 名单，不把空名单宣称为“已避开全部联合阵线”。
- 当前入侵：晨曦 `/incursions/` 中的 `infested_solar_systems`。它不等于完整三神裔 / EDENCOM 名单；按官方更新时间缓存最多 5 分钟。查询失败或时间过旧，开启此规避的计算停止并报错，必须明确关闭开关或恢复接口后继续。
- 官方接口定义：[晨曦 ESI Swagger](https://ali-esi.evepc.163.com/latest/swagger.json?datasource=serenity)。当前地图仍来自标准 SDE，晨曦可能存在不同连接，未全量比对。

## 只读 API 与缓存

- `GET /api/navigation/catalog`：精简星系目录，不含坐标 / 星门 / Three.js。
- `POST /api/navigation/route`：有序 `points`、`modes`、三个本地名单、规避开关。返回三种路径及分段跳数、途经星系资料、安等计数、计算耗时。请求限制 50KB，已知星系才可参与，最多 12 个点位。
- `POST /api/navigation/activity`：只接受已知星系 ID，返回对应统计和独立更新时间。只从固定晨曦上游路径查询，不接受客户端 URL。返回无活动的已知常规星系为 0，但未成功取得整批数据时返回 null（界面 `—`），不能用 0 掩盖错误。
- `GET /api/navigation/environment`：为桌面悬停提供当前快照内所有已知星系的活动统计和萨沙状态；只读、固定三种上游，与路线统计和旗舰入侵共用合并请求、退避和缓存。保留各自时间及错误，不接受外部地址或写数据库。
- 内存共享星图及邻接图，不反复读取数据库。快照文件信息每 5 秒检查一次，更新后自动重建。
- 活动接口 `/universe/system_jumps/` 与 `/universe/system_kills/` 各自缓存；统计窗口为各自 `Last-Modified` 截止的一小时，不是请求时的滚动一小时。按各自 Expires 调度本地缓存，重复用户请求合并为一次。过期批次 / 错误最短 60 秒重试间隔，429 的 Retry-After 最多等待 5 分钟；返回错误和缓存旧批次状态。入侵规避不能使用这些旧批次。
- 没有新增后台同步任务或数据表。桌面地图挂载后通过前端 5 分钟定时复查共享缓存，后台标签页跳过，退出页面取消；没有长期保存活动历史。
- 浏览器请求使用取消及序号保护，过时的请求不能覆盖新路线。列表先出现，活动数据随后填入，不让活动上游阻塞路径计算。

## 验证

- `checks/navigation.check.mjs` 覆盖路线代价、随机图穷举比对、硬规避、途经点重复 / 零跳 / 不连通、边界安等、手工及入侵规则、参数限制、并发共享缓存、失败退避、过期数据、缺失值与错误不能零化。
- `checks/navigation-interaction.check.mjs` 验证手工移动不丢失 / 修改点位、插入位置边界，以及路线高亮时保留背景并适配路线的视图规则；`checks/navigation-auto-view.check.mjs` 覆盖一／二／三条路线联合范围、同路线重复重算和移除繁忙红圈。
- 桌面和手机实际浏览器验证：显式计算、三条路线切换与聚焦、拖动排序、反转、规避持久化、没有页面横向溢出；手机没有星图请求和 WebGL。
- 当前机器实测安帕纳克→吉他，同时计算三模式，100 次平均约 8ms（不含网络、首次文件加载与渲染）。这不是生产环境响应时间保证。

后续旗舰导航需要另行确定舰型、技能范围、合法星系、晨曦地图差异和诱导条件；本预览不作这些判断。
