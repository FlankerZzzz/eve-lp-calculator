# 导航偏好本地保存

常规、旗舰导航各自保存一份 Cookie，互不覆盖，不写业务数据库，不保存路线点位或已计算路线。

## 保存内容和默认值

- 入侵规避、屏蔽名单规避：首次无历史配置时默认开启。
- 常规导航默认只勾选“高安优先”，仍支持多选；保存实际选择，包括用户取消全部选项的状态。
- 旗舰页不再显示三种星门策略，手动星门段固定按最短合法路径计算；兼容读取旧 Cookie，但其中的 `gateMode` 不再参与旗舰计算。常规导航三种偏好保持不变。
- 保留接力范围圈、显示星门连接：默认开启，保存用户选择。
- “仅计算有NPC空间站的星系”：默认关闭，保存用户选择。其筛选范围保持原规则：自动旗舰跳落点与一跳可达查询；不限制手动选点或星门途中，不保证停靠权限。
- 清除计算仅清除点位／路线／工具结果，不重置这些偏好。

## 存储与兼容

- Cookie 名：`eve_nav_preferences_v1`、`eve_jump_preferences_v1`，仅当前主机，`Path=/`，`SameSite=Lax`，有效期一年，HTTPS 下设置 `Secure`。
- 只保存经过白名单校验的开关与策略，未知字段丢弃；Cookie 不携带星系 ID 名单、起终点、业务数据或凭据。
- 屏蔽名单仍存在各页面既有 localStorage 中，最多 500 个星系，避免超过单个 Cookie 容量。
- 没有 Cookie 时迁移旧 localStorage 中明确保存的开关，尊重既有关闭选择；Cookie 存在时以 Cookie 为准，名单本身仍保留。
- 读取失败不自动覆盖损坏内容；用户主动修改后可重新写入。禁止 Cookie 时保留当次页面选择并明确提示，不能声称已经持久化。
- 默认开启入侵规避不等于假设名单可用；缺失、过期或异常时继续按原规则停止新增规划，不能悄悄关闭规避。

## 界面

跳距卡片压为两行：第一行保留当前跳跃半径、数值和光年，第二行完整展示燃料名称与单位光年耗量。按钮按用户提供的原文显示“手动规格线路”，已存在规划时仍显示“重新开始”。
