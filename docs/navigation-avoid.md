# 两种导航的规避与屏蔽

常规和旗舰页共用界面，但保存两份独立的本地设置；不跨页面同步开关或名单，也不写服务器业务库。

- `eve-navigation-avoid-v2`：常规导航；首次读取时迁移旧 `eve-navigation-avoid-v1` 的手工 `avoid` 名单与入侵开关，原文件不删除。旧三神裔/联合阵线标记不再参与计算。
- `eve-jump-navigation-avoid-v1`：旗舰导航；初始空名单。

仅保留“规避入侵星系”和“规避屏蔽列表”两个独立按钮。无历史配置时两项默认开启；已有明确选择优先恢复。关闭名单开关不会清空名单，仍显示红色名称。列表支持展开、中文/英文/拼音/首字母筛选，词条右侧 × 删除；右键菜单和详情卡也可加入/移除。手机端可通过名单中的星系输入框维护，不加载地图。每份名单最多 500 个、ID 去重；损坏的本地配置不会在读取失败时被静默覆盖。

开关及导航偏好分别写入 `eve_nav_preferences_v1`／`eve_jump_preferences_v1` Cookie，保存一年；屏蔽 ID 继续保留在上述 localStorage，避免 500 项名单超过 Cookie 容量。首次使用 Cookie 时迁移旧存储的显式开关值，不删除名单；后续 Cookie 优先。详见 [导航偏好](navigation-preferences.md)。

常规导航保持点击计算/重算后生效。列表开关关闭时请求中不提交屏蔽 ID。起终点/途经点触及当前规避项会明确报错，不自动放行。

旗舰导航将当前有效屏蔽集（按两个开关组合）用于落点候选、附近落点星门搜索、星门路径、手动跳跃、端点检查、一跳直达和完成判定。列表改变不改已有路段，但经过当前规避项的旧路段会标记问题，停止作为可执行路线、禁止继续追加，直至撤销或调整配置。入侵开关开启但数据库快照不可用/过期时，阻止新规划和追加路段，不假设没有入侵。

舰船高安限制、航程、波赫文普通旗舰跳限制等仍独立强制执行，不随规避开关关闭。站点数量仍只提示，不自动排除。

测试覆盖独立存储、旧名单迁移、开关组合、过期数据保护、星门绕路、跳跃端点拒绝、旧路段重验和直达提示无法旁路屏蔽。
