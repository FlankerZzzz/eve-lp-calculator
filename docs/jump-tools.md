# 旗舰导航小工具

工具位于旗舰导航的星图模式旁：小工具：一跳可达（星系输入、计算）｜距离计算（A、到、B、计算）。宽度不足时按工具组换行；手机保留计算与列表，不额外加载 WebGL。

## 规则

- 星系距离：A/B 的真实三维直线光年数。相同星系为 0；不受高安、波赫文、入侵、NPC 站等限制，距离本身不保证能跳。
- 一跳可达：使用当前舰船、技能和启用的规避条件；NPC 站开关开启时仅保留有核验 NPC 站的落点。起点不要求有站。
- 只算一段合法旗舰跳，不经过星门，不做自动绕路。排除自身、高安落点、波赫文及超距星系；边界使用未舍入距离，等于航程可达。
- 入侵规避开启但名单不可用／过期时返回错误，清空旧高亮和列表，不继续展示旧查询为可执行结果。
- 默认按光年升序，可切换降序；等距按星系 ID 稳定排序。排序使用原始距离，显示文本保留最多 4 位小数。
- 一跳可达结果卡片提供小搜索框，支持中英文、拼音和 ID，按当前光年顺序筛选列表，不改变地图高亮或镜头。复制按钮复制当前筛选、排序后的星系及距离（含起点、航程、数量）；无结果时禁用。剪贴板不可用时显示并选中文本供手动复制。重新计算或清除计算后重置搜索。
- 地图白色标记起点、青色高亮可达落点，弱化其余点；拉近并围绕输入星系展示航程。二维仅影响显示，筛选仍按三维距离。
- 距离计算同时高亮 A/B、绘制青色直线，镜头居中并缩放到完整连线；同星系为单点与 0 光年。
- 两种地图效果互斥，新计算替换当前工具效果。计算后点击任意星系仅定位放大并展示详情，不清除范围圈、相关星系高亮、测距连线或结果列表；范围内、范围外及不可达点均一致。结果卡片不提供清除用的“×”；主动清除统一使用“清除计算”按钮。排序、配色和二维／三维切换仍保留计算，舰船、技能、规避条件改变时按原查询重算（条件失效时不保留旧可达点）。
- “回正”始终只恢复默认视角，不清除计算；正下方独立“清除计算”按钮在存在工具结果、旗舰规划或起终点／途经点草稿时可用。点击会清空旗舰起点、全部途经点、终点、路段、范围圈、复制文本、选中卡片和工具结果；保留舰船、技能、规避设置及工具输入框，不重置镜头角度／位置／缩放。手机在工具栏提供相同清除按钮。
- 全局清除先取消自动请求，旧响应不得恢复已清除的路线；完整路线与中断后手动接续状态一并清除。
- 工具查询、排序、星系点选不修改路线起终点／途经点／路段；全局“清除计算”则明确清空所有旗舰规划。工具查询期间暂隐藏旗舰路线覆盖层；显式开始旗舰规划会切回路线规划视图。
- 未包含诱导可用性、角色权限、玩家建筑或实际停靠许可。

## 接入接口

`app/navigation/jump/use-jump-tools.ts` 的 `useJumpTools(context)` 接收现有 graph、ship、skills、blocked、incursions、avoidIncursions、npcStationsOnly、stations 和 now。`blocked` 使用页面当前 `avoidPolicy` 结果，`now` 使用页面的一分钟时钟；不可在每次渲染中无条件新建 graph／blocked／skills。

- `measure(aId,bId)`；读取 `distance`（含 from/to/distance）、`distanceError`；`closeDistance()` 清空。
- `showReach(originId)`；读取 `reach`（含 range、fuelPerLy）、`rows`（id/distance/fuel）、`reachText`、`reachError`。
- `direction`／`setDirection('asc'|'desc')` 控制列表与文本顺序。
- 将 `reachOverlay` 传给现有 `<StarMap reachOverlay={...}/>`，即可执行定位和高亮。排序不会重置镜头；重复查询同一点会重新定位。
- 距离计算使用 `distanceOverlay`；`cancelEffects()` 仅关闭效果并保留输入与计算数据。`active` 记录当前激活工具。
- `closeReach()` 清空查询；查询条件改变会自动重算，错误不保留旧可达点。
- 输入使用现有 `SystemPicker` 解析中英文／拼音／ID，用户确认查询时再调用接口；避免在输入半个名称时触发镜头。

## 验证

- 工具共 14 项自动检查：三维距离、精确航程边界、舰船准入、波赫文、NPC／入侵／屏蔽条件、列表搜索／排序／文本、镜头投影、点选不清除、全局路线清除、取消／清除接口与页面接入；其中包含 90 组固定种子的图与舰船技能组合，对比现有手动旗舰跳合法性。
- 完整构建及回归 311 项通过；TypeScript 和差异空白检查通过。
- 本地隔离浏览器测试覆盖普通／减少动画模式，3D／2D、高亮与列表一致、技能重算、排序不移动镜头、失效数据清空、关闭恢复路线、卸载重挂载，无页面异常。
- 读取真实本地目录的 5485 个星系、63 种舰船，随机技能／起点共 126 组，与独立三维距离、航程、准入及筛选公式对比，4754 个可达落点全部一致。入侵筛选使用真实名单 ID，但固定新鲜时间以隔离筛选计算；真实过期行为另由单元与浏览器测试覆盖。
- lint 为 0 error，保留一条既有本地审计脚本 unused-variable warning，无新增 warning。
