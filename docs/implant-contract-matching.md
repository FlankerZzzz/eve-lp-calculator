# 脑插套装合同匹配

LP 页面中的蓝图套装，公开合同参考价应对应制造后的六件成品，不查询六张蓝图。

查询接口与同步器统一使用 `contractImplantSetsSql()`：

- 已有人工套装及军团关联仍按维护记录与 LP 屏蔽标记校验，不修改这些表。
- 对 LP 兑换方案自动识别额外套装：蓝图通过制造配方映射到成品，普通物品直接使用物品 ID。
- 按同一军团、同一套装英文名称前缀、同一种兑换来源（蓝图或成品）分组。Alpha 至 Omega 六件全部可见且物品 ID 不重复才形成一套，不跨军团或混合来源拼套。
- 两种来源对应同一成品套装时，复用同一成品 ID 签名与合同缓存。
- 合同仍只接受纯 ISK 或纯 PLEX 支付；混合支付、其他交换物品、非完整套装及无效合同保持排除。
- 单张蓝图的合同参考功能不变，仍单独查询蓝图副本。

修复后需重建合同缓存或等下一轮合同同步完成，才能把当前已保存的合同纳入新增套装；无需重新建立物品表或人工新增套装。

回归检查覆盖：无人工套装的蓝图来源、成品 ID 查询、蓝图 ID 不误匹配、同军团完整性、屏蔽单件、纯 ISK/PLEX 与混合支付、缓存重建。
