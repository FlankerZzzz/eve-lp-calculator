# 旗舰跳跃规划 Demo

入口：常规星际导航右上角“旗舰跳跃规划 Demo”，或 `/navigation/jump`。

## 本轮确认的范围

- 支持“自动计算”和原有手动选路。自动计算以 A、途经点、B 为顺序目标，同时搜索旗舰跳和星门；手动规划仍逐段指定落点。
- 所有途经点按 A → 途经 1、途经 1 → 途经 2、最后途经点 → B 分段寻路并拼接，共享星系坐标与跳跃邻接缓存。每段独立采用 2 秒／10 万次入队保护，不再让整条多点路线共用一个 2 秒截止时间。重复途经点仍需真实离开并返回，不能用零段路线重复计数。
- “仅计算有NPC空间站的星系”默认关闭；开启后，自动旗舰跳与一跳可达查询的落点要求有 NPC 空间站，星门途中和经星门到达的目标不要求有站。关闭时，无站星系也可作为合法旗舰跳落点。舰船高安准入、真实三维跳距、波赫文及屏蔽限制仍有效；不保证停靠、诱导或角色权限。
- 自动与手动均使用旗舰页独立的“规避入侵星系”按钮。开启时，所有安等的入侵星系均排除，包括起终点、途经点、跳跃起落点和星门途中；名单不可用或过期时停止计算／追加。关闭时不按入侵名单筛选，也不因该名单不可用而阻止自动计算。
- 自动规则固定：每段目标（途经点或 B）为高安且舰船允许时，尽量旗舰跳到可达低安边界，再经高安星门抵达该点；低安边界按合法过门距离比较，优先减少门数，再比较旗舰跳次数、燃料。禁止零安边界直接过门进高安、低安／零安星门中转及跳入高安。到达明确指定的高安途经点后，可从该点开始下一段旗舰跳；不能借未指定高安中转点重置过门限制。已经在高安内的起点可沿高安星门抵达高安目标。非高安目标只允许旗舰跳。
- 旗舰页不再提供高安优先／低安优先／最短路径选项，手动添加的星门段固定采用最短合法路径，旧 Cookie 中的手动偏好不再参与旗舰计算。常规导航的三种偏好和默认高安优先保持不变。
- 自动找不到完整路线时提示“路径不可达，请自行规划”，保留合法可达前缀，在末端切换手动接续。前缀优先保留已完成的有序途经点，再选择距离下一个目标最近的可达点；这是接续参考，不表示剩余路径可达。原 A/B、途经点和进度保留；无第一跳时在 A 接手。接续后用户可自行选择跳跃／过门，仍强制校验舰船、航程和规避设置。完成前不显示完整路线复制或完成弹窗。
- 后一分段不可达时保留此前已完成的分段，并追加本段合法可达前缀；超时仍明确报计算保护错误，不冒充路径不可达、不返回伪完成结果。禁止跳过失败途经点继续计算后面的点。
- 自动及其手动接续不设固定 30 段上限；全新手动 Demo 保留 30 段限制。保留计算时间及搜索工作量保护；超时或资料异常只明确报错，不冒充不可达或发布未经核验的前缀。两种模式均强制执行舰船准入限制。
- 自动计算通过只读服务端 API 使用批量星图与数据库入侵缓存，不逐星系请求站点。生成后复用地图、逐段校验、撤销、完成提示和路径复制。点位、舰船技能或 NPC 站条件改变后自动路线需重算；开启入侵规避时，名单更新会复核已有自动路线的全部星系，失效即隐藏完成和复制。关闭后恢复未被其他限制阻止的路线。
- 范围按原始三维坐标与舰船技能计算；PC 使用球形网格和三条主截面圈展示，不以二维投影判断能否到达。
- 终点附近先显示最近 5 个低安/00，按星门跳数而不是光年排序，可逐次多显示 5 个。
- **地理信息默认提示，航行合法性始终强制校验**：自动路线的 NPC 站落点限制与入侵规避分别由两个独立开关控制。超距、高安旗舰跳落点、波赫文等不合法操作不显示，添加路段时也用相同规则复核，不能绕过菜单直接添加。
- 受限舰船（包括超级航母、泰坦等）禁止高安起终点；星门寻路排除全部高安节点，有低安/00 绕路时使用合法绕路，无合法路线时隐藏操作并说明原因。高安允许范围沿用用户确认的晨曦名单：黑隐、战略货舰、巨像、山岳。
- 修改舰船或技能后失效的旧路段保留标红，但禁止继续追加，需撤销问题路段或重新开始。NPC/入侵信息不可用不阻止本来合法的手动路段。
- 完成状态同时检查点位变更、全程路段及起终点准入；失效或待重算时不显示绿色完成，途经记录和燃料标为旧规划参考。恢复合法技能/舰船后，未修改的原路线可以恢复有效状态。
- 右键地图星系或候选列表：旗舰跳到这里 / 经星门到这里。也可通过星系详情上的按钮操作。
- 开始规划前也可右键设起点、终点、添加途经点；手机在星系搜索后的点位操作区完成相同设置。最多 10 个途经点，与常规导航复用同一拖动组件，起终点和途经点均可鼠标／触摸拖动、上下移动、删除，最少保留两个点；也可交换起终点（反转整个顺序）。拖动支持取消、边缘滚动和键盘替代按钮；点位使用稳定 key，重复星系及尚未选完的输入不会被丢弃。排序不会自动算路；旧路线标记需重算，并取消旧的自动请求。开始后按实际路段顺序记录完成情况，星门段中间经过也计入，撤销会回滚进度。
- 两种星图默认俯视、正北朝上。共用角落方向标：东/西/南/北/上/下随相机旋转投影，背向轴降低亮度；只保留一个“回正”按钮，同时恢复俯视、正北朝上及默认全图中心与缩放，不清除规划或选点。仍可拖动平移、旋转和滚轮缩放。坐标约定为 SDE +X 东、+Z 北、+Y 上，不宣称官方天球方位。
- PC 左键拖动平移，Shift＋左键旋转，中键也可旋转，右键仅用于菜单，滚轮缩放。画布内阻止浏览器滚动、原生拖拽、文字选择和默认右键菜单，不影响页面其余操作；右键拖动不再平移，也不在松开时误开菜单。浏览器扩展自行接管的全局手势仍可能需用户关闭该站点的扩展手势。
- 添加路段后从末端继续画圈；支持撤销、删除指定段及其后续。修改技能会重新检查已有路段，修改 A/B 需要重新开始。
- 手动星门段复用共用算法的最短合法路径模式；旗舰页有独立的入侵与屏蔽名单开关，不套用常规页面名单。名单改变会重验旧路段但不改线；舰船准入限制始终有效。
- 当前路径点可以合法一跳直达 B 且不会跳过未完成途经点时，弹出“可以直达目的地”，展示跳距、航程与预计燃料。只有“同意完成”才追加最后一跳；“放弃”或 Escape 仅关闭建议，不删除规划，也不重复提醒同一规划状态。新路径/舰船技能状态或重新开始可产生新的建议。高安目的地、超距、旧路线失效、点位待重算及手动模式的 30 段上限不会建议直跳；自动路线不受该段数限制。
- 同意直达或手动跳跃/过门到达 B 后，沿用同一完成状态校验，提示“路线已完成，请在下方复制路径”。下方只在有效完成时展示可复制文本，区分旗舰跳与星门并保留全部过门星系；复制权限不可用时选中文本并提示手动复制，不虚报成功。修改设置使路线失效时，完成提示与复制区域一起隐藏。
- 有效完成时另弹出模态窗口“路线已完成”，PC 覆盖星图，手机同样提示但不加载星图。“关闭”或 Escape 只关闭提示；“前往复制路径”关闭窗口并滚动、聚焦下方路径文本，不自动读写剪贴板。同一轮规划的同一完成路线关闭后不重复弹窗；重新开始或完成另一条路线会再次提醒。路线变脏或失效时未关闭的弹窗也立即消失。
- 路线有效完成后，隐藏当前与所有历史跳跃范围圈，以及下一跳候选和终点附近高亮；保留路线、起终点及已选路径点。撤销到未完成状态后恢复范围圈，“保留接力范围圈”只影响未完成路线。
- 经停点按 A → 经停 1 → 经停 2 → B 显示琥珀色顺序虚线和醒目编号标签；已按序经过的点位带勾，同星系重复经停合并标签但保留全部顺序。它只是计划连线，不自动生成合法路段、不跳过经停点；实际添加的旗舰跳/星门仍是绿/蓝实线。开始含经停点的规划时镜头先展示全程，后续手动接力仍跟随当前点。
- 方向面板可切换“三维 / 纯二维”。二维使用正交镜头、将所有显示层压平到 XZ 平面、固定正北向上，关闭旋转但保留平移、缩放和选点，范围球改为圆。切换时保留规划、观察中心及近似显示尺度并释放旧绘图资源。原始坐标不变，三维测距、航程、燃料及合法性不受二维视觉影响；手机仍不挂载星图。
- 星图下方提供与常规导航共用的配色栏，默认“安全等级”，显示高安/低安/零安及负安图例；当前只开放这一已确认方案，其他方法待确认后再加。基础星点着色与规划候选、琥珀经停点及路线高亮独立，不改变合法性或触发重新计算。
- 悬停星系直接显示鼠标旁的紧凑卡片，保留名称、安等、星域/星座，去掉额外英文及 ID 行。当前确认萨沙入侵时在名称左侧标红“警告：入侵星系”，未知不当成未入侵。四列显示官方一小时过门 / 船毁 / 舱毁 / NPC 毁及各自窗口（北京时间）；附带 SDE NPC 站点数量和真实三维光年距离。只读地图批量缓存，不因悬停查询接口；点击后仍按既有流程核实站点。卡片支持停留延时、边缘避让及淡入，拖动/缩放/离开/失焦立即隐藏，手机仍仅用列表和搜索。
- 背景地名与常规导航共用分级显示：星域 → 星座 → 星系，随观察尺度渐显并自动避让；A/B、途经点、接力点保留专用规划标签，不重复叠加背景星系名。列表定位共用可中断的平滑星座视野过渡，普通地图选点仍不抢占当前接力范围视角。
- 悬停新增共享的 NPC空间站数（SDE 基线），旧快照缺字段显示未核实，不当作 0；不重复附加同一站点行。活动区统一称“最近一小时的地理数据”，指标为过门次数、舰船击毁数、太空舱击毁数、NPC击毁数量；站点数量属于静态资料，仍与活动窗口分开。
- 与常规导航共用无光晕小方点及深色底，规划点用稍大方点和标签强调，星门背景线默认显示并可关闭；背景连线颜色来自两端星系安等，不冒充实际已添加路线。跳跃范围圈保留，完成后按既有规则隐藏。
- 终点可达性卡片明确显示三维距离、航程及超距差额；超距终点、测距虚线与 B 标签以红色显示，金色点仅表示终点附近，不代表当前可跳。屏幕投影不能作为距离判断。已放弃但仍合法可直达时，可点“确认直达终点”重新打开确认，不会自动追加或强行完成超距路线。
- 手机不加载 WebGL，通过列表和搜索完成相同操作。三维旋转、悬停和右键只在 PC 上提供。

## 数据来源与边界

- 星系与星门读取已有 SDE 星图快照，不写业务数据库。明确展示尚未全量核验晨曦。
- NPC 基线来自 `npcStations.jsonl`。点击星系后从晨曦 `/universe/systems/{id}/` 核实完整站点 ID，最多查询前三个站名；失败显示未知，不伪装为无站。悬停只读本地基线，不触发请求。
- 站点查询并发 2、每秒 2 次，复用既有 RequestPool 的重试退避；同星系请求合并，成功缓存一小时，最多缓存 256 个星系。
- 萨沙数据由后台按小时同步，页面打开时读取、可见时每五分钟读取，切回页面时立即读取；隐藏页暂停轮询，同一时间只发起一个读取请求，离开时取消请求。正常显示“自动更新”和后台最近成功同步时间（不是按钮点击时间），不显示常驻刷新按钮；读取失败、格式异常或名单过期时显示“重试”，之后仍自动轮询恢复。页面只读缓存，不触发上游同步。每分钟重新检查名单有效性，开启入侵规避时失效即阻止规划／完成复制，不清空既有点位或路线；关闭是不按入侵筛选，不代表已确认安全。
- 舰船来自已核验的晨曦 63 艘裸船快照。跳距为基础 × (1 + 0.2 × 校对等级)。燃料节约与战略货舰的舰船技能修正分别乘算，每段向上取整。估算不包含装备/植入等，也不适用于通道/导管运输。
- 玩家建筑不接入，不把公开 ID 当已知可停靠地点。不完整判断诱导、舰船停靠限制、角色权限等游戏内条件。
- 路线只保留在当前页面，刷新会清空。无新增数据库表、同步任务或 OAuth 配置。
- 舰船补充快照在导出、服务端读取、页面加载时共用同一校验：ID 唯一、跳距与耗油有效、技能耗油加成及最大航程燃料结果在安全范围内，站点引用及核验时间完整；API 返回前还验证星系坐标及星门引用。无效导出不覆盖旧文件，API 不发布不完整数据，503 错误不缓存，错误消息不暴露本地路径。页面显示错误并提供“重新加载基础资料”，不把异常快照直接送入绘图或规划计算。

## 准备运行数据

先按 `docs/jump-drive-data.md` 生成完整的晨曦舰船审计快照，再运行：

```bash
node scripts/v2/export-jump-demo.mjs path/to/sde.zip path/to/audited-jump-ships.json
```

默认输出到被 Git / Docker 忽略的 `docker-data/v2/jump-demo.json`，与 `star-map.json` 放在业务数据库同目录。不要提交原始运行目录或业务数据库。发布代码不会自动向生产创建快照或触发同步。
