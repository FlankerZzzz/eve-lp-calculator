# 旗舰点选与主权卡片

旗舰与常规导航点选星系均调用同一星图的 `focus()` 平滑定位，保持选中星系居中、按所在星座范围缩放，支持二维与三维以及减少动画偏好。右键仍仅打开菜单，不自动移动镜头。旗舰地图新增共用 `SelectedSystemCard`，包含规划点位、屏蔽、距离及通过合法性检查的跳跃/过门动作。点选不改变路线或点位，不提交新的路段；原下方规划及站点信息保留。

两种导航的选中/悬停卡片均增加主权信息：优先 NPC 势力，其次玩家联盟，再次玩家军团。合法的无归属记录显示“未宣称主权”；没有对应数据时显示“待核实/未提供归属”，不猜测。错误或过期快照保留可参考旧值并显式提示。名称暂缺不展示错误实体，显示“名称待补齐”。

卡片明确标注“晨曦主权”来源，保留接口原值，不等同于静态背景势力或阵营战争占领状态。实测晨曦 `/sovereignty/map/` 对吉他返回 `faction_id=500006`（统合部），不得在测试或展示中硬编码成加达里，也不能因此推断接口其他归属必然与游戏一致。进一步校正口径需单独核实。

已有 `navigation_cache` 增加一个 `kind=sovereignty_names` JSON 快照，没有新增物理表。每次地理同步成功取得主权后，收集 `faction_id/alliance_id/corporation_id`，ID 去重、每批最多1000个，通过晨曦 `/universe/names/` POST 批量查询并校验完整性后原子发布。正常仅增加一次批量请求；不逐星系查询、不依赖LP表、不在网页点选时补查名称。失败保留旧名称并在地理同步日志/状态提示；空缺显示占位。地理默认仍每小时一次。Web仅从数据库读取名称和归属。

徽标复用现有 `/api/data/entity-icon` 磁盘内容寻址缓存与失败占位图。新增玩家联盟及玩家军团的晨曦分支；玩家徽标只请求晨曦 `Alliance/{id}_{size}.png` 或 `Corporation/{id}_{size}.png`，不使用国际服同ID做回落。NPC势力图标沿用现有静态势力徽标策略，原LP图标逻辑不变。图片是独立资源缓存，不把首次图片缓存缺失解释为主权查询失败。

地图环境请求在页面与星图之间共享；旗舰页面仅加载一次环境，不因悬停或选择再次请求地理资料。手机端仍不加载星图/全量地图环境，保留既有搜索与规划功能。

参考：[CCP 图像服务说明](https://developers.eveonline.com/docs/services/image-server/)。晨曦批量名称和两种玩家徽标URL均以实际接口测试确认可用。
