# 晨曦服 LP 兑换收益分析

面向 EVE Online 晨曦服的忠诚点（LP）兑换辅助工具。项目结合 LP 商店目录、伏尔戈市场订单、历史成交、蓝图材料与公开合同，展示兑换成本、税后利润、流动性风险和单位 LP 收益。

市场价格和订单深度会持续变化，页面结果是快照估算，不构成成交保证。缺少真实收单、材料订单不足或产出收单不足的方案会显示风险提示，不应直接当作可立即实现的收益。

## 主要功能

- 按势力和 NPC 军团查看 LP 商店兑换方案。
- 比较兑换材料、制造材料、税后利润与 LP 收益。
- 查看吉他 4-4 当前订单深度和近期市场历史。
- 汇总蓝图制造成本与产出收益，并查看六件套脑插和纯蓝图拷贝的公开合同价格。
- 按浏览器本地保存常用军团收藏夹；收藏数据不会上传或在用户之间共享。
- 提供热销榜、价值榜、企业详情、组合估算和数据同步审计页。

## 数据口径与更新周期

- 基础目录：手动执行全量同步，更新势力、军团、中文物品名、LP 商店方案和蓝图资料。
- 当前订单：后台每 30 分钟读取伏尔戈区域订单，以双槽方式发布完整快照；应用使用吉他 4-4 相关订单。
- 历史成交：每天 00:30 后补跑近期市场日线。
- 首页榜单：上海时间每日 09:00、15:00、18:00、21:00 重新计算并保存快照。
- 公开合同：独立按 30 分钟周期刷新六件套脑插与蓝图拷贝合同缓存。合同参考比例只作市场参考，不参与利润计算。

全局无效数据策略集中在 `lib/data-policy.ts`。Sync 页的“显示无效数据”按钮只展开审计信息，不会启用被排除的数据，也不会改变其他用户的结果。

## Docker 部署

新机器首次部署使用 `git clone`；已有工作副本更新时才使用 `git pull --ff-only`。

部署前在仓库根目录创建不会进入 Git 或镜像的 `.env`，为 Sync 页手动控制设置独立强口令：

```dotenv
SYNC_ADMIN_TOKEN=请替换为足够长的随机口令
```

后台同步容器使用隔离的内部凭据，浏览器无法通过 Nginx 伪造该凭据。Sync 页只把管理口令保留在当前浏览器标签页的会话存储中。

```bash
git clone <repository-url> eve-lp-calculator
cd eve-lp-calculator
mkdir -p docker-data/sqlite docker-data/wrangler
docker compose up -d --build
docker compose ps
```

首次启动会创建空的 SQLite 数据库。随后应从仅限私网访问的 `/sync` 页面执行基础资料同步，并等待订单、历史、榜单和合同任务产生数据。

已有部署更新：

```bash
git pull --ff-only
docker compose up -d --build
docker compose ps
```

运行数据保存在 `docker-data/sqlite/`，不会写入 Git。升级或迁移前应备份该目录；不要把开发机数据库打包进镜像或提交到仓库。

## 本地开发与检查

需要 Node.js 22.13 或更高版本，以及 pnpm。

```bash
pnpm install --frozen-lockfile
pnpm run dev
pnpm run check
pnpm run lint
npx tsc --noEmit
```

当前完整生产运行路径是 Docker Compose、Nginx 与 SQLite。仓库内保留的 Cloudflare/Vite 构建配置不包含后台同步服务和私网同步入口的完整生产能力，不能直接替代 Docker 部署。

## 隐私与安全边界

- 应用不提供账号系统；军团收藏使用当前浏览器的本地存储。
- `.env*`、`AGENTS.md`、本地数据库、密钥、日志和构建产物应同时被 Git 与 Docker 构建上下文排除。
- `/sync` 和 `/api/sync/*` 的 Nginx 私网限制是网络边界，不等同于用户身份认证；不要将这些入口直接暴露给不受信任网络。
- Sync 写入接口使用后台内部凭据，手动启动、暂停或重算还需要部署者配置的 `SYNC_ADMIN_TOKEN`。
- 默认 Nginx 访问日志可能包含来源 IP、Referer 和 User-Agent，部署者应按自己的隐私要求配置保留周期与日志轮转。

发布或更新远端服务器前，应先完成本地构建、自动化测试、接口检查和数据备份；远端操作需由部署者明确授权。
